# Cursor Crew

작은 도트 슬라임이 내 마우스 **살짝 옆·뒤**에서 통통 튀며 따라다니다가, 마우스를 멈추면 옆에 앉습니다.
그때 펫에 마우스를 올리거나 클릭하면 **기능 메뉴**(자주 가는 링크, 이 페이지 메모, URL 복사, 맨 위로)가 펼쳐지는 크롬 확장(MV3)입니다.

평소엔 화면을 거의 가리지 않습니다. 기본 1마리, 36px, 이름표 없음, 클릭은 전부 페이지로 통과.

```
  ↖ (내 마우스)
      ▄██▄          ← 멈추면 옆에 앉음
     █•  •█   ┌────────────────────────┐
     ▀▀▀▀▀▀   │ ● GitHub     github.com│  ← 호버하면 펼쳐지는 메뉴
              │ ● 메모     메모 있음 •  │
              └────────────────────────┘
```

## 로컬에서 설치하기 (압축해제 로드)

1. 크롬 주소창에 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**를 누르고 이 `cursor-crew/` 폴더를 고릅니다.
4. 퍼즐 아이콘을 눌러 Cursor Crew를 고정합니다.
5. 이미 열려 있던 탭은 **새로고침**해야 펫이 나타납니다(설치 후 새로 여는 탭은 바로 동작).

코드를 고친 뒤에는 `chrome://extensions`에서 Cursor Crew 카드의 **새로고침(↻)** 을 누르고, 보고 있던 탭도 새로고침합니다.
로컬 파일(`file://`)에서도 쓰려면 확장 **세부정보 → 파일 URL에 대한 액세스 허용**을 켭니다.

## 쓰는 법

- **따라다니기**: 마우스를 움직이면 펫이 마우스 뒤쪽으로 처지며 통통 따라옵니다. 펫이 여럿이면 줄줄이. 이때 클릭은 전부 페이지로 갑니다.
- **앉기**: 마우스를 0.45초쯤 멈추면 펫이 마우스 오른쪽 아래(화면 끝이면 반대쪽)에 앉습니다. 근처에서 움직이는 동안은 그대로 있고, 멀리 가면 다시 따라옵니다.
- **메뉴**: 앉은 펫에 마우스를 올리거나 클릭하면 메뉴가 펼쳐집니다. 항목을 누르면 실행되고, 펫 위에 짧은 말풍선으로 결과를 알려 줍니다.
  - 링크: 클릭 = 새 탭(바로 옆), <kbd>Shift</kbd>+클릭 = 지금 탭, <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+클릭 = 뒤쪽 탭
  - 메모: 작은 메모장이 뜨고 페이지(주소의 경로까지)별로 자동 저장. 메모가 있는 페이지에선 펫 머리 위에 보라색 점. 메모장에서 치는 키는 페이지 단축키(유튜브 `k`, 깃허브 `s` 등)로 새지 않습니다.
  - <kbd>Esc</kbd>나 바깥 클릭으로 닫힙니다.
- 페이지 입력창에 글을 쓰기 시작하면 펫이 거의 투명해지고, 마우스를 움직이면 돌아옵니다. 창 밖으로 나가거나 전체화면이면 숨습니다.
- **켜기/끄기**: 툴바 아이콘 클릭 또는 <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>. 꺼지면 아이콘에 `OFF` 배지. 단축키는 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다.

## 설정 (옵션 페이지)

툴바 아이콘 우클릭 → **옵션**.

- **모양**: 스킨(슬라임 · 커서 · 내 이미지, 움직이는 미리보기), 개수(1~3), 크기(24~64px), 평소 투명도, 펫별 색
- **기능 메뉴**: 항목별 색 · 이름 · 기능 · 링크 주소, 순서 바꾸기, 추가(최대 8개)·삭제
- 멈춘 뒤 앉기까지 걸리는 시간, 펫을 띄우지 않을 사이트, 저장된 메모 목록

설정은 `chrome.storage.sync`에, 메모와 올린 이미지는 `chrome.storage.local`에 저장됩니다. 바꾸면 열려 있는 탭에도 바로 반영됩니다.

## 스킨 (겉모습)

겉모습은 `skins.js`, 따라다니기·메뉴·기능은 `content.js`로 나뉘어 있어서 스킨만 갈아 끼울 수 있습니다.

| 스킨 | 설명 |
| --- | --- |
| `slime` (기본) | 코드로 그린 16×16 도트 슬라임. 걸을 때 눌림→늘어남→공중→착지 4프레임으로 통통, 쉴 때 숨쉬기 2프레임과 깜빡임, 움직이는 방향으로 눈이 돌아감. 펫 색으로 자동 채색 |
| `cursor` | 멀티플레이어 화살표 커서 |
| `image` | 옵션에서 올린 그림(128px로 줄여 저장). 걸을 때 통통 튀고 진행 방향으로 살짝 기울어짐 |

새 스킨 만들기: `skins.js`의 `SKINS`에 하나 추가합니다.

```js
const ghost = {
  label: "유령",
  create(color, size, opts) {
    const el = document.createElement("img"); // 기준점은 발밑 가운데: left -size/2, top -size
    // ...
    return { el, update({ t, dt, vx, vy, speed, hover }) { /* 매 프레임: 프레임 바꾸기, 흔들기 */ } };
  },
};
```

옵션 페이지 스킨 목록에 자동으로 나타납니다. 도트 스프라이트 PNG를 쓰고 싶으면 `chrome.runtime.getURL("sprites/…png")`로 불러오고, `manifest.json`의 `web_accessible_resources`에 그 경로를 추가하면 됩니다.

## 기능 추가하는 법

1. `defaults.js`의 `actions`에 한 줄: `weather: { label: "날씨 보기" }`
2. `content.js`의 `ACTIONS`에 같은 이름의 함수: `weather(item, ev, crew, pet) { crew.toast(pet, "맑음"); }`
3. 탭을 열거나 다른 크롬 API가 필요하면 `chrome.runtime.sendMessage`로 `background.js`에 맡깁니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `manifest.json` | MV3. 권한은 `storage`만, 모든 http(s) 페이지에 콘텐츠 스크립트 |
| `defaults.js` | 기본 설정과 기능 목록 |
| `skins.js` | 겉모습(슬라임 도트 렌더러, 커서, 이미지) |
| `content.js` | 펫 위치·물리(Shadow DOM), 앉기, 메뉴, 기능 실행, 메모장 |
| `background.js` | 켜기/끄기(아이콘·단축키), 배지, 링크 탭 열기 |
| `options.html/.css/.js` | 설정 페이지 |
| `test/harness.html` | 확장 없이 `content.js`를 돌려 보는 테스트 페이지 |
| `test/chrome-shim.js` | 테스트용 `chrome.*` 흉내(진짜 확장 안에서는 아무 일도 안 함) |

확장 없이 미리보기: 이 폴더에서 `python -m http.server 5180`을 실행하고 http://localhost:5180/test/harness.html 과 http://localhost:5180/options.html 을 엽니다(저장은 그 페이지의 localStorage에 됨).

## 한계

- 크롬이 확장을 막는 페이지(`chrome://`, 웹 스토어, PDF 뷰어)에선 나타나지 않습니다.
- iframe 안(예: 임베드된 에디터)에서는 마우스 이동이 최상위 페이지로 전달되지 않아, 그 위에 있는 동안은 펫이 멈춰 있습니다.
- 모든 사이트에 콘텐츠 스크립트를 넣기 때문에 설치 시 "모든 웹사이트의 데이터 읽기 및 변경" 권한 안내가 뜹니다. 페이지 내용을 읽거나 밖으로 보내는 코드는 없습니다(메모·이미지만 로컬에 저장).
