# Cursor Crew

이름표를 단 커서들이 내 마우스를 졸졸 따라다니다가, **마우스를 잠깐 멈추면 제자리에 서서** 클릭할 수 있게 되는 크롬 확장(MV3)입니다.
커서 하나하나가 기능 하나를 맡습니다: 자주 가는 링크 열기, 이 페이지에 메모 남기기, URL 복사, 맨 위로.

```
 내 마우스 ↖
            ↖ GitHub
              ↖ YouTube
                ↖ Gmail
                  ↖ 메모 •      ← 이 페이지에 메모가 있으면 점이 붙음
```

## 로컬에서 설치하기 (압축해제 로드)

1. 크롬 주소창에 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**를 누르고 이 `cursor-crew/` 폴더를 고릅니다.
4. 퍼즐 아이콘을 눌러 Cursor Crew를 고정합니다.
5. 이미 열려 있던 탭은 **새로고침**해야 커서가 나타납니다(설치 후 새로 여는 탭은 바로 동작).

코드를 고친 뒤에는 `chrome://extensions`에서 Cursor Crew 카드의 **새로고침(↻)** 을 누르고, 보고 있던 탭도 새로고침합니다.

로컬 파일(`file://`)에서도 쓰려면 확장 **세부정보 → 파일 URL에 대한 액세스 허용**을 켭니다.

## 쓰는 법

- **따라다니기**: 마우스를 움직이면 커서들이 오른쪽 아래에 비스듬히 줄지어 따라옵니다(화면 끝에선 반대쪽으로). 이때는 클릭이 전부 페이지로 통과합니다.
- **잡기**: 마우스를 0.45초쯤 멈추면 커서들이 그 자리에 섭니다. 그 근처에서 움직이는 동안은 따라오지 않으니, 원하는 커서로 가서 클릭하세요. 멀리 벗어나면 다시 따라옵니다.
- **호버**하면 이름표가 커지며 무슨 일을 하는지 보여 줍니다(`↗ github.com`).
- 링크: 클릭 = 새 탭(바로 옆), <kbd>Shift</kbd>+클릭 = 지금 탭, <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+클릭 = 뒤쪽 탭
- 메모: 클릭하면 작은 메모장이 뜹니다. 페이지(주소의 경로까지)별로 자동 저장되고, <kbd>Esc</kbd>나 바깥 클릭으로 닫힙니다. 메모장에서 치는 키는 페이지 단축키(유튜브 `k`, 깃허브 `s` 등)로 새지 않습니다.
- 페이지 입력창에 글을 쓰기 시작하면 커서들이 흐려지고, 마우스를 움직이면 돌아옵니다. 창 밖으로 나가거나 전체화면이면 숨습니다.
- **켜기/끄기**: 툴바 아이콘 클릭 또는 <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>. 꺼지면 아이콘에 `OFF` 배지가 붙습니다. 단축키는 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다.

## 설정 (옵션 페이지)

툴바 아이콘 우클릭 → **옵션**.

- 커서별 **색 · 이름 · 기능 · 링크 주소**, 순서 바꾸기, 추가(최대 8개)·삭제
- 멈춘 뒤 잡히기까지 걸리는 시간
- 커서를 띄우지 않을 사이트(도메인, 하위 도메인 포함)
- 저장된 메모 목록(열기·삭제)

설정은 `chrome.storage.sync`(크롬 계정끼리 동기화)에, 메모는 `chrome.storage.local`에 저장됩니다. 바꾸면 열려 있는 탭의 커서들도 바로 바뀝니다.

## 기능 추가하는 법

1. `defaults.js`의 `actions`에 한 줄: `weather: { label: "날씨 보기" }`
2. `content.js`의 `ACTIONS`에 같은 이름의 함수: `weather(m, ev, crew) { … }`
   (`m`은 커서 설정 객체, `crew.flash(m, "텍스트")`로 이름표에 잠깐 메시지를 띄울 수 있음)
3. 탭을 열거나 다른 크롬 API가 필요하면 `chrome.runtime.sendMessage`로 `background.js`에 맡깁니다.

옵션 페이지의 기능 선택 목록에는 자동으로 나타납니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `manifest.json` | MV3. 권한은 `storage`만, 모든 http(s) 페이지에 콘텐츠 스크립트 |
| `defaults.js` | 기본 커서 구성과 기능 목록(세 곳이 함께 씀) |
| `content.js` | 커서 렌더링(Shadow DOM), 따라다니기·잡기 물리, 기능 실행, 메모장 |
| `background.js` | 켜기/끄기(아이콘·단축키), 배지, 링크 탭 열기 |
| `options.html/.css/.js` | 설정 페이지 |
| `test/harness.html` | 확장 없이 `content.js`를 돌려 보는 테스트 페이지 |
| `test/chrome-shim.js` | 테스트용 `chrome.*` 흉내(진짜 확장 안에서는 아무 일도 안 함) |

확장 없이 미리보기: 이 폴더에서 `python -m http.server 5180`을 실행하고 http://localhost:5180/test/harness.html 과 http://localhost:5180/options.html 을 엽니다(저장은 그 페이지의 localStorage에 됨).

## 한계

- 크롬이 확장을 막는 페이지(`chrome://`, 웹 스토어, PDF 뷰어)에선 나타나지 않습니다.
- iframe 안(예: 임베드된 에디터)에서는 마우스 이동이 최상위 페이지로 전달되지 않아, 그 위에 있는 동안은 커서들이 멈춰 있습니다.
- 모든 사이트에 콘텐츠 스크립트를 넣기 때문에 설치 시 "모든 웹사이트의 데이터 읽기 및 변경" 권한 안내가 뜹니다. 페이지 내용을 읽거나 밖으로 보내는 코드는 없습니다(메모만 로컬에 저장).
